# Anthill

**A**dvanced **N**eural **T**argeting & **H**yper-spectral **I**ntelligence for **L**and & **L**ithosphere.

Discovery intelligence for minerals, gemstones, energy and water. Pick a resource,
drop a pin anywhere on Earth, and get a ranked target map with an intelligence brief.

## Run locally

```bash
npm install
cp .env.example .env   # optional: add API keys for live intelligence reports
npm run dev              # or: npm start
```

Open http://localhost:8080

## Pages

| Route | Purpose |
|---|---|
| `/` | Landing page |
| `/explorer` | Interactive target map |
| `/pricing` | Plans for mines |
| `/contact` | Pilot scan requests |

## Disclaimer

Outputs are for exploration planning only — not verified resource evidence.
Validate all targets with field work before economic decisions.
